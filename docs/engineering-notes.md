# 실무 노트

## `file://`로 열면 2D가 된다
- 증상: `index.html`을 더블클릭해 열면 경기장이 2D로 나온다.
- 원인: `file://`에서는 WebGL이 jpg/webp를 텍스처로 올릴 때 출처 보안 오류가 난다. 그래서 Stage가 2D로 자동 전환한다.
- 대응: 3D 확인은 `npm run serve`(기본 포트 8787)로 띄운 `http://127.0.0.1:8787/`에서 한다.

## 헤드리스 Chromium에서 WebGL 켜기
- `tools/browser.js`는 `--use-angle=swiftshader --enable-unsafe-swiftshader`로 띄운다. 이 플래그를 빼면 헤드리스에서 WebGL이 꺼져 스모크가 항상 2D로만 실행되고, 3D 경로는 검증되지 않는다.
- 브라우저는 새로 받지 않고 `%LOCALAPPDATA%/ms-playwright/chromium-*`의 설치본을 쓴다. 없으면 `CHROME_PATH` 환경변수로 지정한다.

## Windows PowerShell 5.1이 한글 파일을 깨뜨린다
- 증상: `(Get-Content f -Raw).Replace(...) | Set-Content f`를 거친 파일의 한글 주석이 `?ㅽ봽…`처럼 깨진다.
- 원인: PowerShell 5.1은 BOM 없는 UTF-8을 ANSI(CP949)로 읽는다.
- 대응: 편집기 도구를 쓰거나, `[IO.File]::ReadAllText(f, [Text.Encoding]::UTF8)` / `WriteAllText(..., UTF8Encoding($false))`를 쓴다. 고친 뒤 `[媛濡寃]` 같은 깨짐 글자를 grep해서 확인한다.

## `node --test test/`가 Node 24에서 실패한다
- 증상: `Cannot find module '…\test'` 오류가 난다.
- 원인: Node 24는 디렉터리 인자를 모듈 경로로 해석한다.
- 대응: `node --test`처럼 인자 없이 실행한다. 이 경우 `test/**/*.test.js`를 자동으로 찾는다.

## 배틀을 끝내는 턴에는 "보호막 해제" 이벤트가 없다
- 엔진은 승패가 난 턴에 보호막 종료 이벤트를 내보내지 않는다. 그래서 화면은 배틀·컷신을 시작할 때 Stage의 보호막·얼음·오라를 직접 초기화한다. 새 연출 상태를 추가할 때도 같은 위치에서 초기화해야 다음 판으로 상태가 넘어가지 않는다.

## 캐릭터 그림 만들기 (2img)
- 2img(gpt-image-2)는 투명 배경을 직접 내주지 않는다. "flat solid pure green (#00FF00) chroma-key background"로 생성한 뒤 크로마키로 알파를 만든다. 테두리 픽셀 중앙값을 배경색으로 잡고, 거리 60~150을 알파 0~1로 대응시키고, G를 max(R,B)+6 이하로 눌러 녹색 번짐을 없앤다. 생성 결과가 이미 RGBA 투명일 때도 있으므로, 알파 최솟값을 먼저 확인한다.
- 실존 IP 이름(포켓몬·디지몬)을 프롬프트에 넣으면 생성이 차단될 수 있으므로, 프롬프트는 외형 묘사로만 쓴다.
- 배치: 알파 바운딩 박스를 잘라 정사각 캔버스(한 변 = 긴 변/0.94)에 발끝이 아래 3% 위로 오도록 붙이고, 768로 줄여 webp(q90)로 저장한다.
- 이로치는 포즈를 맞추기 위해 원본을 HSV로 재채색한다.
  - 나루냥: 색상 170~255°를 +62° 이동한다.
  - 설냥이: 연한 하늘색 털 그림자(채도 0.38 미만, 명도 0.62 초과)를 **털로 분류**한다. 그렇게 하지 않으면 털 그림자가 결정과 함께 분홍색으로 번진다.
  - 싸가지냥: 어두운 저채도 털을 황갈색으로 바꾸되, 명도 0.09 미만인 선은 짙은 갈색으로 남긴다.
- 확인: `node tools/gallery-shot.js`가 기본 38장(고양이 18 + 진화형 18 + 메탈가디언몬·블랙)과 이로치 36장, 모두 74장이 768px로 로드되는지 검사하고 `tools/out/gallery.png`를 남긴다. 갤러리는 진화형을 기본형 바로 뒤에 둔다.
- 스크립트: 키아웃·배치는 `python tools/art/process_sprite.py <원본.png> assets/mon/<id>.webp [--key green|magenta|blue] [--spill lo,hi]`로 한다. 이로치는 `python tools/art/shiny.py [id ...]`가 `RULES` 표의 id별 규칙으로 `<id>_shiny.webp`를 만든다. 원본 생성물은 `tools/out/art_raw/`에 둔다.
- 키 색 교훈:
  - 초록 몸(풀·독 고양이)은 녹색 키를 쓰면 몸까지 투명해지므로 "flat solid pure magenta (#FF00FF)" 배경으로 생성한다. 마젠타 번짐 제거는 가장자리 띠(반투명 + 4px)에만 적용한다. 몸 전체에 적용하면 보라색 몸이 회색으로 바랜다.
  - 마젠타 키를 쓸 몬스터는 눈·연기도 마젠타가 아닌 색(금색 눈, 보라·남색 연기)으로 지정한다. 마젠타 눈은 키아웃되어 구멍이 난다.
  - 불꽃·오라처럼 배경 위에 반쯤 비치게 그린 부분은 거리 기준 알파만으로는 불투명으로 남아 올리브색 얼룩이 된다. 그래서 키 색 초과량(녹색 키면 G-max(R,B))으로 알파를 한 번 더 낮추고 배경 몫을 빼서 원래 색을 되살린다(unmix). 기본값은 25~200이고, 불꽃 고양이처럼 녹색 그림자가 남으면 `--spill 10,80`으로 낮춘다. 청록 몸(드래곤)은 10,80이면 몸 안쪽이 비치므로 기본값을 쓴다.
  - 녹색으로 요청해도 생성기가 배경을 지운 RGBA를 줄 때가 많다(15종 중 7종). 이때 몸통 알파가 252~253이고 배경에 1~2짜리 잡티가 깔리므로, 알파 8~245를 0~1로 다시 편다.
- 실존 IP를 연상시키는 조합(노란 고양이 + 번개 꼬리 + 빨간 볼)은 이름을 쓰지 않아도 차단된다. 빨간 볼을 빼고 "jagged zigzag-shaped tail, white-blue sparks"처럼 바꿔 쓰면 통과한다.
- 이로치 재채색에서 색상 폭이 넓은 부위(풀 고양이의 초록 60~105°)를 그대로 이동하면 빨강과 노랑이 섞여 탁해진다. 이런 부위는 `set_h`로 색상을 하나로 고정하고 채도를 올린다.
- 진화형 18종(`<id>2`, 원본은 `tools/out/art_raw/evo/`, 프롬프트는 같은 이름의 `.prompt`):
  - 프롬프트에 기본형의 상징(나루냥 이마 물방울, 싸가지냥 줄무늬 꼬리, 격투냥 빨간 머리띠·손 붕대 등)을 다시 적어야 진화 전과 이어져 보인다. 19번 생성 중 4번은 배경을 지운 RGBA로 나왔다.
  - 흰색·하늘색으로 반쯤 비치는 효과(냉기, 흰 전기 불꽃, 모래 먼지)는 기본 spill 값에서 청록·올리브 얼룩으로 남는다. `--spill 0,40`이면 원래 색으로 돌아온다. 반투명 나비 날개는 0,40이면 날개 안쪽까지 비치므로 기본값을 쓴다. 반투명 연기 몸(고스트)은 10,80을 쓴다.
  - 흰 도복 + 검은 띠 + 빨간 머리띠 조합은 소매를 고쳐도 유명 격투 게임 주인공을 떠올리게 한다. 공개 사이트라 권왕냥(punch2)은 남색 조끼·금색 띠·이마의 금색 표식으로 다시 만들었다(머리띠 없음, 기본형의 빨간 손 붕대는 유지). 의상 색을 바꾸는 것이 가장 확실하다.
  - 이로치는 기본형 규칙을 그대로 쓰되, 검은 털을 황갈색으로 바꾸는 싸가지냥 진화형은 `v_pow`(명도 감마, 0.3)와 `vfade`(vmax 경계 완화)로 흰 가슴은 두고 어두운 털만 밝힌다. 설냥이 진화형 결정은 원본 색상이 205~215°라 +68°만 옮겨야 보라가 된다(+88°면 자홍).

## 필드(탑뷰 맵)
- 맵은 `js/maps.js`의 글자 타일이다. 행 길이가 모두 같아야 하고, 건물 자리는 '#'로 채운다. 실수는 `test/world.test.js`가 잡는다(건물 자리·문 앞 통행·워프 도착지·NPC/도구/표지판 도달성·트레이너 시야). 맵을 고치면 `npm test`부터 돌린다.
- NPC를 문 앞이나 길목 한가운데에 세우면 도달성 테스트가 실패한다. 실제로 시작 마을 할머니가 집 문을 막은 적이 있다.
- `PWorld.loadMap`은 NPC를 맵마다 복사한다. 시야에 걸려 다가온 트레이너는 그 방문 동안만 위치가 바뀌고, 맵을 다시 불러오면 제자리로 돌아간다.
- 자동 점검 창구 `window.__pocatmon.walk / pressA / enterMap`은 실행만 시키고 바로 돌아온다. 배틀이 끝날 때까지 기다리는 Promise를 돌려주면 Playwright `evaluate`가 그 배틀을 진행할 수 없어 교착된다. 스모크는 `ow.busy`·대화창·화면 값을 폴링한다.
