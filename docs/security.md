# 보안

## 보호 대상
- 로그인·계정·서버가 없다. 수집하는 개인정보도 없다. 브라우저 저장소에 두는 것은 `pocatmon.save`(진행·파티·도감)와 `pocatmon.muted` 두 키뿐이다. v1의 `pocatmon.run`·`pocatmon.unlocked.black`이 남아 있을 수 있다. 모두 게임 진행에 쓰는 값이라 민감하지 않다.
- 공개 저장소에 올라가는 것은 `battle/` 아래 게임 파일뿐이다. 상위 폴더의 원본 ChatGPT 스크린샷 5장은 저장소 밖에 있으며 커밋하지 않는다. 이 폴더 바깥 파일을 저장소에 넣지 않는다.

## 자격 증명
- GitHub 배포는 운영체제 git 자격 증명 관리자에 저장된 토큰을 쓴다. 토큰을 출력하거나, 파일·커밋·로그에 남기지 않는다. 저장소 안에 토큰을 읽는 스크립트를 두지 않는다.

## 입력 신뢰
- 저장소에서 읽은 저장 데이터는 `PEngine.isValidSave`로 형식(버전 2, 몬스터·기술 id, 레벨·HP·PP 범위, 상태이상 값, 배지 id)을 검사한다. 통과하지 못하면 기록이 없는 것으로 본다. 손상되거나 조작된 값 때문에 화면이 깨지는 일을 막기 위해서다. 숫자를 조작해 강한 몬스터를 만드는 일은 1인용 게임이라 막지 않는다.
- 화면에 표시하는 문자열은 데이터 파일에 든 고정 문구와 엔진이 만든 메시지뿐이다. 사용자 입력 텍스트를 받지 않는다.
