# 보안

## 보호 대상
- 로그인·계정·서버가 없다. 수집하는 개인정보도 없다. 브라우저 저장소에 두는 것은 `pocatmon.unlocked.black`, `pocatmon.run`, `pocatmon.muted` 세 키뿐이며, 모두 게임 진행값이라 민감하지 않다.
- 공개 저장소에 올라가는 것은 `battle/` 아래 게임 파일뿐이다. 상위 폴더의 원본 ChatGPT 스크린샷 5장은 저장소 밖에 있으며 커밋하지 않는다. 이 폴더 바깥 파일을 저장소에 넣지 않는다.

## 자격 증명
- GitHub 배포는 운영체제 git 자격 증명 관리자에 저장된 토큰을 쓴다. 토큰을 출력하거나, 파일·커밋·로그에 남기지 않는다. 저장소 안에 토큰을 읽는 스크립트를 두지 않는다.

## 입력 신뢰
- 저장소에서 읽은 런 기록은 `PEngine.isValidRun`으로 형식(버전, 몬스터 id, 길이 4 배열, 판 번호 0~3, 컷신 종류)을 검사한다. 통과하지 못하면 기록이 없는 것으로 본다. 손상되거나 조작된 값으로 화면이 깨지지 않게 하기 위함이다.
- 화면 문자열은 데이터 파일의 고정 문구와 엔진 메시지뿐이다. 사용자 입력 텍스트를 받지 않는다.
