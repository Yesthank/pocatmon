## 확인 범위의 빈틈
- 실제 휴대폰(저사양, 카카오톡 인앱 브라우저)에서 측정하지 않았다.
- 스모크는 관장 1~6과 붉은 달 폐허 화면을 직접 지나가지 않는다. 같은 배틀 코드를 쓰며, 엔진 테스트와 시뮬레이션이 그 데이터를 검증한다.
- 배포하지 않았다. 공개 사이트는 아직 v1(4연전)이다.
