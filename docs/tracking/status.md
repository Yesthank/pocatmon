# 현재 상태

## 완료 (검증됨)
| 영역 | 상태 | 근거 |
|---|---|---|
| 배틀·런·저장 엔진 | 완료, 테스트 통과 | `npm test` 20/20. 상성표 전체, 순서, 얼림·풀죽음·보호막·단계 한계, 회복 상한, 반동 동시 기절, 런 순서 3종, 이로치 고양이 한정, 이어하기 저장·복원·삭제, 쓰기 실패 저장소 |
| 밸런스 | 완료, 범위 통과 | `npm run sim` 시작 몬스터별 클리어율: 나루냥 50.0% · 설냥이 48.6% · 싸가지냥 74.3% · 메탈가디언몬 66.8% · 블랙 70.6%. 배틀당 평균 3.4~4.6턴 |
| 3D 경기장 + 2D 대체 | 완료, 화면 확인 | `node tools/stage-shot.js` 3D·2D 모두 오류 0. 배경 5종과 이펙트 전 종류를 스크린샷으로 확인 |
| UI·화면 흐름·효과음·컷신 3종 | 완료, 스모크 통과 | `npm run smoke`: 3D는 타이틀→선택→미리보기→배틀→결과까지, 2D는 배틀까지 진행. 콘솔 오류 0, 가로 넘침 0 |
| 캐릭터 일러스트 5종 + 고양이 이로치 3종 | 완료 | `node tools/gallery-shot.js` 8장(일반·이로치 10칸) 로드 |

## 확인 범위의 빈틈
- 실제 휴대폰(저사양 기기, 카카오톡 인앱 브라우저)에서의 프레임과 소리는 측정하지 않았다. 헤드리스 SwiftShader에서만 약 60fps를 확인했다.
- 스모크는 시드 1에서 첫 판 패배로 끝나는 경로를 자동 검증한다. 클리어·컷신·이어하기 경로는 일회성 스크립트로 오류 0을 확인했지만, `npm run smoke`에는 들어 있지 않다.

## 남은 일
없음. 계획한 범위를 모두 구현했다. 3:3 팀·교체·아이템·배경음악·온라인 대전은 만들지 않기로 한 범위다.
