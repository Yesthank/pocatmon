# 0003 패배하면 런 전체를 처음부터

> **대체됨 (2026-10-06):** v2 확장에서 0004로 대체되었다. 지금은 전멸해도 센터에서 회복하고 수집한 것을 잃지 않는다. 아래는 v1 당시의 기록이다.

**맥락.** 4연전 도중에 졌을 때 어떻게 처리할지 정해야 했다. 추천안은 "그 판부터 재도전"이었다.

**결정.** 사용자가 긴장감을 위해 "처음부터 다시"를 골랐다. 지면 저장된 런을 즉시 지우고 몬스터 선택으로 돌아간다. 브라우저가 닫혔을 때를 위한 이어하기는 따로 둔다. 이어하기는 중단된 게임을 복구하는 기능이며, 패배를 되돌리는 수단이 아니다.

**대안.** 그 판부터 재도전: 끝까지 보기 쉽지만 긴장감이 사라져 기각했다.

**결과.** 밸런스는 "무난하게 플레이하면 클리어 가능"해야 한다. 그래서 `npm run sim`의 클리어율 35~95% 범위가 배포 조건이다. 이어하기 기록은 패배 즉시 지워야 하며, 지우지 않으면 패배를 우회하는 방법이 생긴다.
