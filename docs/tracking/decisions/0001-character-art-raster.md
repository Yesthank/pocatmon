# 0001 캐릭터 그림: 손으로 그린 SVG → 2img 일러스트(webp)

**맥락.** 처음에는 몬스터 5종을 코드로 그린 SVG(512×512, 그라디언트·외곽선)로 만들었다. 실제 화면에 띄워 보니 원본 설정 시트(애니 일러스트)와 비교해 "간지가 안 난다"는 사용자 피드백이 나왔다. 특히 늑대형 두 종이 각진 로봇처럼 보였다.

**결정.** 2img(gpt-image-2)로 설정 시트의 특징을 살린 일러스트를 생성하고, 크로마키로 배경을 제거해 `assets/mon/*.webp`(768×768)로 쓴다. 이로치는 같은 그림을 재채색해 포즈를 맞춘다. 외부 인터페이스 `Sprites.spriteURL(id, {shiny})`는 그대로 두고 반환값만 파일 경로로 바꿨다.

**대안.**
- SVG를 더 정교하게 손으로 그리기: 원본의 털 질감·장갑 광택·역동적 포즈를 코드로 작성한 SVG 패스로 재현하기 어려워 기각했다.
- 생성 이미지를 벡터로 변환(vtracer): 색이 계단처럼 끊기고 파일이 커져 일러스트 품질이 떨어지므로 기각했다.
- 이로치를 따로 생성: 포즈가 달라져 같은 몬스터로 보이지 않아 기각했다.

**결과.**
- 캐릭터 파일 하나의 크기는 약 100~175KB다(SVG는 수 KB였다).
- 그림 구도(발끝 여백 3.1%, 높이 약 92%)가 Stage에서 접지 위치와 말풍선 위치를 계산하는 값(`Sprites.FOOT`, `ART_TOP`)과 묶여 있다.
- 메탈가디언몬·블랙의 이로치 그림은 없다. 게임 규칙상 이로치는 고양이 상대에게만 나오기 때문이다. 이 규칙을 바꾸면 그림을 새로 만들어야 한다.
- 그림을 바꾸려면 2img 생성 → 키아웃 → 배치 과정을 다시 거쳐야 한다(손으로 직접 편집할 수 없다).
