# 0005 탑뷰 필드·도구·상점·진화·이벤트 (RPG 강화)

**맥락.** 사용자가 Tuxemon(파이썬 오픈소스 몬스터 수집 RPG)과 Pokémon Essentials(RPG Maker 기반 팬게임 키트)를 참고해 RPG 게임성을 강화해 달라고 요청했다(2026-10-07). v2는 메뉴로 지역을 고르는 구조였다.

**결정.** 사용자가 고른 범위는 다음과 같다.
- 도구·상점·돈, 진화, 스토리·NPC·퀘스트를 넣는다. 특성·성격은 넣지 않는다.
- 필드는 걸어 다니는 탑뷰 타일 맵이다(추천안).

구현은 다음과 같이 했다.
- 렌더러: 캔버스 2D `js/field.js`. 타일·건물·캐릭터 도트를 모두 코드로 그린다.
- 판정·규칙: `js/world.js`(순수 로직)가 이동, 수풀 조우, 트레이너 시야, 조사, 조건, 경로 찾기를 맡는다.
- 데이터: 맵·이벤트는 `js/maps.js`, 도구·상점·트레이너·진화는 `js/data.js`에 있다.
- 이벤트: Tuxemon처럼 '조건 목록 + 행동 목록' 스크립트로 쓰고, `main.js`가 대화창·배틀·상점을 열며 실행한다.
- 저장: v3. 어제 배포한 v2 기록은 자동으로 옮긴다.

**참고 범위.** 두 프로젝트에서 가져온 것은 설계뿐이고, 코드·에셋·데이터는 가져오지 않았다. Tuxemon 코드는 GPL-3.0이라 가져오면 저장소 전체가 GPL이 되고, Essentials는 원작 유래 데이터가 섞여 있기 때문이다. 참고한 설계는 다음과 같다.
- 수풀 한 걸음당 조우 확률, 트레이너 시야와 접근 순서
- 상금 = 기본값 × 마지막 몬스터 레벨, 배지 수에 따라 늘어나는 상점 품목
- 회복약 단계(20/60/120/전부), 스프레이 100걸음
- 진화 형식(대상 + 레벨), 이벤트의 조건·행동 구조

수치와 이름은 모두 우리 것이다(예: 생선 간식·참치 통조림·마따따비).

**대안.** 다음 두 안을 검토했으나 고르지 않았다. 특성·성격도 고르지 않았다.
- 메뉴형 유지: 지역 화면에 마을 버튼만 추가한다.
- 지역 그림 위에 탭할 지점만 찍는다.

**결과.**
- 밸런스가 바뀌었다. 길목 트레이너와 진화가 들어가 플레이어가 강해졌으므로, 해안·화산 관장 에이스를 진화형으로 바꿨다.
- 시뮬레이션은 길목 트레이너와 라이벌을 먼저 상대하고 진화하는 플레이로 바꿨다. 수련 배틀은 평균 170번에서 105번으로 줄었다.
- 필드는 스모크에서 실제로 걸으며 확인한다. 대상은 인트로, 라이벌 배틀, 수풀 조우, 센터, 상점, 메뉴, 최종전, 이어하기다.
