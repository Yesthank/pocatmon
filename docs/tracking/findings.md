# 미해결 문제

## 블랙 메탈가디언몬의 최대 HP가 메탈가디언몬보다 낮다
- 조건: 현재 수치(블랙 HP 116, 메탈 HP 146; 최종 보스 배율 ×1.15).
- 증상: 최종 보스인 블랙이 3번째 상대인 메탈가디언몬보다 덜 단단하다. 대신 공격·방어·스피드가 더 높아, 빠르게 잡히거나 빠르게 이기는 유리대포처럼 동작한다. "더 강해진 흑화형"이라는 설정과 체감이 어긋날 수 있다.
- 영향: 게임은 정상 진행되고 클리어율도 범위 안이다. 연출상의 위압감 문제다.
- 지금 못 고치는 이유: 블랙 HP를 140으로 올리면, 보스전에서 지는 비율이 높은 설냥이의 클리어율이 약 50%에서 37%로 떨어져 하한(35%)에 붙는다. 나머지 몬스터는 거의 변하지 않는다(시드 고정 1000런 비교). 다른 수치와 함께 다시 맞춰야 해서, 실제 플레이 감상을 받은 뒤 판단할 일이다.
- 접근: 블랙 HP를 올리는 만큼 데스 임팩트 위력이나 방어를 낮추고 `npm run sim`으로 재확인한다.

## 설냥이·나루냥은 시뮬레이션 플레이어보다 사람이 더 어렵게 느낄 수 있다
- 조건: 시뮬레이션 정책은 HP 35% 미만에서 정확히 회복한다.
- 증상: 설냥이는 패배가 3~4판(강철 상대)에 몰리고, 나루냥은 1~2판(얼음 상대)에 몰린다. 회복 타이밍을 놓치는 사람은 클리어율이 표보다 낮아진다.
- 지금 못 고치는 이유: 실제 플레이 데이터가 없다.
- 접근: 플레이 감상을 받은 뒤 해당 구간의 상대 배율이나 회복량을 조정한다.
